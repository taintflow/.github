# taintflow

**Security research. Practical tooling.**

taintflow is a home for open-source security tools, research, and experiments focused on how software is built, shipped, and used.

## Areas of interest

- **Application security** - code analysis, taint tracking, and vulnerability research.
- **Software supply chain security** - CI/CD hardening, dependency security, build integrity, and provenance.
- **AI security** - agent permissions, sandboxing, and adversarial evaluation.

## Building in the open

The aim is to turn security ideas into tools, reproducible examples, and technical write-ups that other engineers can inspect, use, and improve.

## Contribute

Ideas, bug reports, and pull requests are welcome. Start with an issue in the relevant repository.
